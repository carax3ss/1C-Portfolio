# Внешняя обработка "Поиск контрагентов без ИНН"

Внешняя обработка (файл `.epf`) для конфигурации 1С:Управление торговлей 11. 
Предназначена для быстрого поиска контрагентов, у которых не заполнен ИНН.

## Зачем это нужно
При ведении учета часто возникает ситуация, когда у контрагентов не заполнен ИНН (например, при быстром вводе новых клиентов). Бухгалтерии и менеджерам необходимо оперативно находить таких контрагентов для корректировки данных. Штатный поиск 1С не позволяет сделать это в один клик.

## Что делает
1. При нажатии на кнопку «Найти» выполняется SQL-запрос к справочнику «Контрагенты».
2. Отбираются только те элементы, у которых поле «ИНН» пустое, и которые не помечены на удаление.
3. Результат (Ссылка и Наименование) выводится в таблицу на форме обработки.

## Как запустить
1. Скачайте файл `ПоискКонтрагентовБезИНН.epf` из папки `build`.
2. В 1С (в режиме «1С:Предприятие») выберите меню **Файл -> Открыть...**
3. Выберите скачанный файл `.epf`.
4. Нажмите кнопку «Найти».

## Технические детали
- Код написан с разделением на клиент (`&НаКлиенте` — обработка нажатия кнопки) и сервер (`&НаСервере` — выполнение запроса и работа с таблицей значений).
- Для вывода результата используется реквизит формы типа «ТаблицаЗначений».
