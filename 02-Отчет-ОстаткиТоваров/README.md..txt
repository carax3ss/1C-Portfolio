# Внешний отчет "Остатки товаров на складах" (СКД)

Внешний отчет для конфигурации 1С:Управление торговлей 11, разработанный с использованием Системы компоновки данных (СКД).

## Зачем это нужно
Менеджерам и руководителям часто требуется оперативно посмотреть, сколько и какого товара лежит на конкретном складе на определенную дату, без запуска тяжелых стандартных отчетов.

## Что делает
1. Использует виртуальную таблицу остатков регистра накопления «ТоварыНаСкладах».
2. Выводит данные в виде сгруппированной таблицы: Склад -> Номенклатура -> Остаток.
3. Автоматически считает итоги по каждому складу.
4. Позволяет пользователю интерактивно выбирать дату, на которую нужно получить остатки (через настройки отчета).

## Как запустить
1. Скачайте файл `.erf` из папки `build`.
2. В 1С (в режиме «1С:Предприятие») выберите меню **Файл -> Открыть...**
3. Выберите скачанный файл.
4. Нажмите кнопку «Сформировать». При необходимости выберите нужную дату в настройках.

## Технические детали
- Для получения данных использована виртуальная таблица `РегистрНакопления.ТоварыНаСкладах.Остатки`.
- В СКД настроены ресурсы (`Сумма(Остаток)`) и параметры (`Период`).
